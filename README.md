Tracked Gear‑Driven Tractor Robot
Overview:
A VEX‑based tractor robot built for a PLTW engineering challenge. The robot was required to move forward and backward using gears only, with optional wireless control. The goal was to design a stable, consistent drivetrain that could travel a set distance as slowly as possible without stopping.

Assignment Requirements:
-Must use ONLY VEX parts (metal allowed)
-Must use a gear‑driven drivetrain (no chains, no belts)
-Motor → axle → gear → gear → wheels
-Must move forward and backward
-Wired control required; wireless optional
-Must travel the full test distance without stopping or malfunctioning
-Slowest robot to reach the finish wins
-Time allowed: 1.5 weeks

Design Process
Version 1 — 3‑Gear High‑Speed System
-Inspired by high‑performance supercar gearing
-Very fast acceleration
-Extremely inconsistent
-Gears kept climbing over each other and grinding
-Caused instability and unpredictable movement
-Failed reliability criteria
I tried forcing the gear system but the gears were meeting at a right-angle with spur gears, which are only cut for parallel shafts. The next version is where I was able to fix the issue by adding a different type of gears, something that worked with the downward shaft design.

Version 2 — 2‑Gear Bevel Gear System
-Switched to the rounded, using 2 sets of Bevel gears
-These gears meshed smoothly and prevented gear climbing
-Much slower, but extremely stable
-Passed all consistency requirements
-Chosen as the final design 

Performance Test
-Control mode: wired (wireless kept cutting out)
-Distance: classroom test length (teacher‑defined)
-Final time: 14 seconds
-No stops, no stalls, no mechanical failures
-Slight sideways tilt during run, but still completed the course

It sparked my curiosity and passion for robotics, and it’s the project that opened the door to all the future engineering work I’m excited to create.

Because this experience taught me engineering doesn't have to stay limited to the workbench, its skills and knowledge can be applied into real life systems like in my case.
